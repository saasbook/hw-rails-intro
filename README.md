# CHIP 5.3: Rails Intro: add features to RottenPotatoes

[View this assignment on GitHub](https://github.com/saasbook/hw-rails-intro)

[Read the assignment instructions](instructions/README.md)

In this homework you will add a feature to an existing simple Rails app and deploy the result publicly on a cloud hosting service, either Render or Heroku. We will run live integration tests against your deployed version.

General advice: This homework involves modifying RottenPotatoes in various ways. Git is your friend: commit frequently in case you inadvertently break something that was working before! That way you can always back up to an earlier revision, or just visually compare what changed in each file since your last “good” commit.

**Remember, commit early and often!**
